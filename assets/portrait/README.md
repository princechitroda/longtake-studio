# Founder portrait

Put the portrait here, named exactly `prince.jpg`.

- Roughly 4:5 portrait (taller than wide)
- At least 900px on the short side
- Graded dark, so it sits inside the page rather than on top of it

`index.html` points at `assets/portrait/prince.jpg`. If the file is missing the
figure removes itself rather than showing a broken-image icon, so the page never
looks broken while the photo is pending.
